# PsEduca Backend

Backend del proyecto **PsEduca**, una portal desarrollad como parte del Máster en Ingeniería Informática (Planificación y dirección de proyectos). Este componente gestiona la lógica de negocio y la interacción con la base de datos, proporcionando servicios esenciales para el funcionamiento del sistema.

## 🚀 Características

- Implementado en **PHP**.
- Arquitectura modular con carpetas como `controller`, `model`, `service`, `validation`, entre otras.
- Gestión de excepciones personalizada.
- Soporte para carga de archivos y manejo de rutas estáticas.
- Pruebas unitarias incluidas en la carpeta `test`.

## 🗂 Estructura del proyecto

- `controller/`: Controladores que manejan las solicitudes HTTP.
- `model/`: Definición de modelos de datos.
- `service/`: Lógica de negocio y servicios auxiliares.
- `validation/`: Validaciones de datos de entrada.
- `uploads/`: Carpeta para almacenamiento de archivos subidos.
- `test/`: Pruebas unitarias y de integración.

## 🛠 Requisitos

- PHP 7.4 o superior.
- Servidor web (por ejemplo, Apache o Nginx).
- Base de datos compatible (MySQL, PostgreSQL, etc.).
